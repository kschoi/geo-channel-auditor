# 고객은 우리 매장을 어떻게 볼까?

Geo Channel Auditor · 매장 인사이트 v0.4

## 목적과 사용 흐름

흩어진 후기를 읽고, 주변 인구를 살펴보고, 다음에 해볼 일을 고릅니다. 매장 사장님이 유지할 강점과 확인할 불편을 근거와 함께 판단하도록 돕습니다.

1. 동네·실제 매장명·업종을 입력합니다. 경쟁점은 최대 2개 직접 고릅니다.
2. 기본값인 **찾은 전체 기간**으로 읽거나 최근 90·180·365일을 선택합니다.
3. 후기에서 칭찬과 불편을 보고 항목별로 경쟁점과 비교합니다.
4. 행정동을 선택해 실제 성별×연령 인구를 살펴봅니다.
5. 원하면 공개 합성 인물 10명으로 가상 반응 실험을 합니다.
6. 근거가 연결된 제안을 골라 안내 문구·사진·운영 점검으로 이어갑니다.

전체 고객 만족도·방문 확률·매출·시장 점유율·다른 AI의 인용률은 측정하지 않습니다. 리뷰 사이트 전체 수집을 보장하지 않습니다.

## 공개 후기 분석

| 항목 | 처리 기준 |
| --- | --- |
| 수집 | 매장당 Liner Search 3회·Search Agent 1회. 공식 상권 자료 Search 2회 |
| 매장 구분 | 상호·지역·지점 표현 대조. 다른 지점과 관련 없는 자료 제외 |
| 해석 | Router가 인용문·자료 ID·항목·감정·글의 성격 추출 |
| 인용 검증 | 해당 자료에 인용문이 실제로 있는지 서버에서 대조. Agent의 생성 답변 자체는 사실 근거로 사용하지 않음 |
| 글의 성격 | 고객 경험·운영자 주장·기사/설명·미확인 분리. 주요 집계는 고객 경험 문서 |
| 중복 | 추적 URL·네이버 모바일 URL 정규화. 문서×항목당 한 번 집계 |
| 감정 | 긍정·부정·혼합·중립. 같은 문서의 상반된 경험은 혼합 |
| 전체 기간 | 찾은 문서 중 날짜 미상도 주요 집계에 포함. 날짜 미상 건수와 개별 표시 유지 |
| 기간 지정 | 확인한 게시일이 선택 기간 안인 문서만 주요 집계. 날짜 미상은 별도 |
| 행동 | 대상 매장의 확인된 불편·혼합 경험에는 점검 제안, 긍정 경험에는 강점 활용 제안 |

기본값 `period_days=0`은 찾은 자료를 넓게 읽는 모드입니다. 모든 과거 리뷰를 수집했다는 뜻은 아닙니다. 날짜 미상을 오늘 게시된 문서로 바꾸지 않습니다. 최근 흐름을 읽으려면 기간을 지정합니다.

감정·글의 성격은 AI 해석입니다. 인용 일치 검사가 실제 방문이나 해석의 정확성을 인증하지는 않습니다. 숫자에서 인용문·게시일·출처 링크로 이동할 수 있어야 합니다.

### 경쟁점과 행동 제안

품질·맛, 응대·서비스, 가격·가치, 분위기·공간, 접근성, 대기, 청결을 비교합니다. 모든 매장에 같은 검색 예산과 기간 조건을 적용합니다. 같은 지역·업종인지, 게시 시점과 출처 구성이 비교 가능한지도 확인합니다.

매장별·항목별 고객 경험 문서가 5건 미만이면 우열 비교를 제한합니다. 5건은 표시 규칙이며 통계적 유의성을 보장하지 않습니다. 전체 기간에 날짜 미상이 포함되면 시점이 맞는 비교라고 주장하지 않습니다. 숫자는 근거를 읽기 위한 출발점이며 매장 순위가 아닙니다.

행동 제안은 확인한 문장에 연결합니다. 한 번 나온 불편을 반복된 문제로 확대하지 않습니다. 긍정 근거만 있는 경우에도 칭찬받은 경험을 사진·메뉴 설명·안내에서 더 잘 드러내는 일을 제안할 수 있습니다. 근거가 없는 장점이나 약점은 만들지 않습니다.

## 세 자료의 경계

| 자료 | 실제로 나타내는 것 | 함께 섞지 않는 것 |
| --- | --- | --- |
| 공개 후기 | 이번 검색에서 확인한 문서의 경험·감정 | 전체 고객 수·전체 만족도 |
| 행안부 인구 | 특정 행정구역에 등록된 성별·연령 인구 | 매장 방문객·리뷰 작성자 |
| 합성 인물 반응 | 공개 합성 사례의 취향과 매장 근거를 연결한 모델 반응 | 실제 여론·연령대별 만족률·방문 확률 |

공개 리뷰 작성자의 성별·연령을 이름·사진·말투로 추정하지 않습니다. 인구와 후기를 개인 단위로 연결하지 않습니다. 합성 결과를 실제 후기의 부족한 칸에 넣지 않습니다.

## 실제 지역 인구

### 원자료와 권리

- 제공처: [행정안전부 행정동별 연령별 인구현황](https://jumin.mois.go.kr/ageStatMonth.do).
- 기준일: **2026-10-31**, 취득일: 2026-11-20. 매월 말 기준 주민등록 통계이며 외국인은 제외합니다. 등록 구분은 전체(거주자·거주불명자·재외국민)입니다.
- 공식 화면의 공개 CSV 다운로드로 취득했습니다. 별도 인증키가 필요하지 않습니다. 파일은 CP949, 1,167,845바이트입니다.
- 이용범위 근거: [공공데이터포털의 같은 종류 행안부 CSV 카탈로그](https://www.data.go.kr/data/15097972/fileData.do)는 무료·이용허락범위 제한 없음으로 안내합니다. 앱에 원자료 출처를 표시합니다.
- 원본 SHA256: `d0e63aa22b4456b4c8796e1536ba9637ff4ae5f88669a45ac0de07b630d224a3`.

### 스냅샷과 재현

`app/data/population-202610.json`은 전국·시도·시군구·읍면동 **3,921개 행정구역**의 공개 스냅샷입니다. 실행 때 외부 통계 서버를 호출하지 않습니다. 기준월을 바꾼 새 파일을 자동으로 받는 기능은 없습니다.

파일의 `dataset`에는 원자료 URL, 다운로드 URL·POST 조건, 기준일·취득일, 원본 해시, 집계 방식, 이용범위 근거가 들어 있습니다. 공식 다운로드 주소는 `https://jumin.mois.go.kr/downloadCsvAge.do?searchYearMonth=month&xlsStats=3`입니다. 저장된 조건으로 CSV를 다시 받아 해시와 합계를 대조할 수 있습니다.

원본의 성별×10세 구간을 직접 읽습니다. 60~69·70~79·80~89·90~99·100세 이상은 60세 이상으로 합칩니다. 성별 합계와 연령별 합계를 곱해 교차값을 만드는 방식은 사용하지 않습니다.

- 화면의 12칸: 여성·남성 × 10대·20대·30대·40대·50대·60세 이상.
- `display_total`: 이 12칸의 합계, 즉 10세 이상 인구. 칸의 비율 분모입니다.
- `under10`: 0~9세 여성·남성·합계.
- `total`: 전체 연령. `display_total + under10.total`과 같아야 합니다.
- 모든 지역의 성별 총계, 각 연령의 남녀 합계, 전체 총계와 코드 중복을 검사합니다.

지역은 후보를 검색한 뒤 사용자가 직접 선택합니다. 산본1동·산본2동처럼 여러 후보가 있어도 임의로 합치지 않습니다. 행정동은 실제 상권 경계나 도보 반경이 아닙니다. 전국·시도·시군구·읍면동 행을 동시에 합산하면 인구가 중복되므로, 한 번에 선택한 한 지역을 보여줍니다.

### 추가 상권 문서

Liner가 찾은 공식 상권 문서는 별도의 출처 자료로 남깁니다. 수치 후보는 공식 도메인, 인용문·지역·기간·단위·정수값의 연결을 검사합니다. 검색 문서의 수치와 주민등록 스냅샷을 같은 지표로 합치지 않습니다. 확인할 수 없는 값은 0으로 바꾸지 않습니다.

## 가상 고객 반응 실험

### 합성 인물 출처와 선택

[NVIDIA Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea)는 NVIDIA Corporation이 공개한 성인 합성 페르소나 데이터입니다. [공식 설명](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea/blob/main/README.md)에 따라 **CC BY 4.0** 출처를 표시합니다. 실제 분포를 참고해 만든 인공 데이터이며, 실제 인물의 인터뷰나 고객 명단이 아닙니다.

[Hugging Face 공개 rows API](https://huggingface.co/docs/dataset-viewer/rows)로 첫 100행을 받아, 여성·남성 각각 20·30·40·50·60세 이상 구간에서 처음 나온 1명을 선택했습니다. 10대는 포함하지 않습니다. 표본은 총 10명이고 각 성별×연령 칸은 **1명**입니다. 모집단을 대표하는 확률 표본이 아닙니다.

원본 UUID·행 번호·성별·나이·출신 지역·음식 취향 등 필요한 필드만 추출해 `app/data/synthetic-personas.json`에 담습니다. 원문에서 선택·필드 축소를 했다는 변경 내역, 출처·라이선스·다운로드 정보도 남깁니다. 전국 여러 지역의 예시이며 선택한 상권 주민으로 바꾸지 않습니다.

### 입력과 판단

사용자가 실험 버튼을 눌렀을 때 Liner Router를 추가 호출합니다. 모델에는 각 합성 인물의 **음식·외식 취향**과 서버가 이미 검증한 **대상 매장 원문 근거**를 전달합니다. 표시용 성별·나이·이름·출신 지역은 판단 입력에서 제외합니다. 경쟁점 근거와 사용자가 새로 보낸 임의 인용문은 입력으로 받지 않습니다.

응답은 관심·망설임·혼합·보류, 조건부 반응 이유, 방문 전에 확인할 질문, 취향 원문 조각과 매장 근거 ID로 구성합니다. 취향 인용이 실제 입력에 있는지, 매장 근거가 허용된 것인지 검사합니다. 연결을 검증하지 못한 반응은 미확인으로 남깁니다.

화면에는 **가상 실험 · 실제 고객 조사 아님**을 표시합니다. 나이·성별은 예시 인물을 구분하는 표시이며 집단의 성향을 증명하지 않습니다. 각 칸을 눌러 취향·이유·근거를 읽습니다. 1명의 반응을 “20대 여성 만족률 100%” 같은 집단 통계로 확대하지 않습니다.

### 요청 범위

서버가 분석 완료 시 발급한 보고서 토큰으로만 실행합니다. 보고서의 검증된 대상 매장 근거를 최대 24개 보관하며 키는 저장하지 않습니다. 보고서 보관은 최대 30분·6개이고, 같은 보고서의 Router 호출은 최대 1회입니다. 반복 클릭으로 새 유료 호출을 만들지 않습니다. 실험 요청 제한 시간은 180초입니다.

실험 결과는 실제 손님에게 물어볼 질문을 고르는 가설입니다. 실제 조사와 검증 없이 방문 확률·매출 효과로 해석하지 않습니다.

## 화면과 제작

첫 화면에는 핵심 질문·통합 검색창·시작 버튼을 둡니다. 경쟁점·기간·키 설정과 세부 출처·호출 기록은 접습니다. 결과에서는 요약과 인용, 항목별 비교, 실제 인구, 가상 반응, 다음 행동을 읽습니다.

- 비교 사각형의 빗금은 부정 문서 비율을 나타냅니다. 문서 수와 숫자 표를 함께 제공합니다.
- 실제 인구는 성별·연령별 숫자와 분포 그림으로 보여줍니다. 비율은 표시 연령의 분모를 함께 적습니다.
- 합성 반응은 별도의 실험 화면입니다. 각 칸의 예시 수와 출처를 드러냅니다.
- `—`는 미확인, `0`은 확인한 0건입니다. 빈 공간을 임의 수치로 채우지 않습니다.

수집 진행과 취소, 일부 실패, 분석 오류·시간 초과를 구분합니다. 외부 실패를 성공한 가상 결과로 덮어쓰지 않습니다. 데스크톱과 390px 모바일에서 실제 렌더링을 확인합니다.

제출 영상은 최종 앱 화면을 녹화합니다. 1920×1080 전체를 시연 화면으로 채우고 별도 상단 제목을 넣지 않습니다. 한국어 음성은 사용자의 로컬 Chatterbox 여성 음성 설정을 사용합니다. FFmpeg로 영상·음성을 합치고 흰 자막에 텍스트 너비만큼의 검정 65% 불투명 배경을 얹습니다. 앱의 고객용 기능과 별도로 제작하는 제출물입니다.

## 보안·운영 범위

- Liner 키는 환경변수 또는 일회성 입력으로 받습니다. 브라우저에 영구 저장하지 않으며 응답·오류·로그에서 제거합니다.
- 공개 자료·모델 출력은 신뢰하지 않는 입력입니다. 화면에는 텍스트로 표시하고 HTTP(S) 링크만 허용합니다.
- 고객 명단이나 리뷰 CSV 업로드는 없습니다. 공개 후기·공식 집계·출처가 있는 합성 자료를 분리해 사용합니다.
- 대상 포함 최대 3개 매장, 동시 수집 최대 3개, 매장별 최대 24개 자료, 공식 상권 자료 최대 12개입니다.
- 인식 분석 전체 요청은 최대 360초입니다. 취소·연결 종료 시 작업을 정리합니다. 공급자에서 이미 처리한 호출의 비용 취소는 보장하지 않습니다.
- 카드뉴스는 별도 화면에서 대상 매장만 다시 검토합니다. 경쟁점 자료를 홍보 원고로 넘기지 않습니다. AI 배경은 실제 매장 사진으로 표시하지 않습니다.

## 검증 기준

1. 실제 검색 자료에서 매장·지점과 경쟁점을 구분한다.
2. 없는 인용·잘못된 자료 ID·다른 매장 근거를 제외한다.
3. 전체 기간과 기간 지정의 날짜 미상 처리, 문서 중복·혼합 감정을 검증한다.
