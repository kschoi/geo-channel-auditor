# 5분 데모 영상 촬영 대본 — Geo Channel Auditor v0.2.0

> 라이너 .EXE-THON 제출물 2/3 · 팀 클로클립(최경선)
> 목표 길이 **4분 45초** (심사 상한 5분) · 1080p 30fps · 내레이션 + 화면 녹화
> 저장소: https://github.com/kschoi/geo-channel-auditor

이 대본은 **읽으면서 그대로 녹음할 수 있는 완성 원고**입니다. 대괄호 `[ ]` 는 말하지 않고 행동만 하는 지시입니다.

> **주의 — 숫자와 결핍 항목은 화면에서 읽는다.** 아래 대본에 적힌 점수와 결핍 제목은 **데모 픽스처(가상 매장) 기준 예시**입니다. LIVE Liner API로 촬영하면 결과가 달라지므로, `⟨ ⟩` 로 표시된 자리는 **화면에 실제로 나온 값**을 읽습니다. 대본을 외우지 말고 화면을 따라가며 말하는 것이 원칙입니다.

> **용어 원칙.** 이 앱이 분석하는 인용 출처는 **Liner Search · Liner Search Agent가 상권 질문에 실제로 인용한 출처**입니다. GPT·Perplexity·Gemini·Claude 등 다른 AI의 인용을 모으는 기능이 아니므로, 영상에서도 “AI 인용 출처”가 아니라 **“Liner 인용 출처”**, “Liner 검색·에이전트 인용”이라고 말합니다. Liner Router는 결핍 진단과 채널별 보완 콘텐츠를 생성하는 단계로 설명합니다.

## 1. 촬영 전 준비 (15분)

**환경**

- [ ] `git clone https://github.com/kschoi/geo-channel-auditor && cd geo-channel-auditor`
- [ ] `cp .env.example .env` 후 `LINER_API_KEY=...` 입력 (커밋 금지 — `git status`로 `.env` 미포함 확인)
- [ ] `uv run uvicorn app.main:app --reload` (또는 `.venv/bin/uvicorn app.main:app`)
- [ ] `http://127.0.0.1:8000` 접속 → 상단 배지가 **LIVE**(초록 점)인지 확인
- [ ] `http://127.0.0.1:8000/api/health?probe=true` 로 **크레딧 잔액 확인**
      — 진단 1회 호출 수: 채널 문구를 넣으면 **5회**(검색 3 + 에이전트 1 + 라우터 1), 채널 문구를 비우면 자동 수집 검색 2회가 더해져 **최대 7회**. 예비로 2~3회분 여유를 둔다
- [ ] 샘플 1종을 먼저 1회 돌려 **LIVE 응답이 정상**인지, 단계별 소요 시간이 몇 초인지 미리 재 본다 (촬영 중 로딩 길이를 예상하기 위해)

**화면**

- [ ] 브라우저 창 1600×1000, 확대 100%, 북마크바·확장 프로그램 아이콘 숨김
- [ ] 시크릿 창 사용 금지(키 입력이 매번 필요해짐) / 다른 탭·메신저 알림 모두 종료(**알림 팝업은 개인정보 노출 사고 1순위**)
- [ ] 마우스 커서 강조(클릭 표시) 켜기, 클릭 전 0.5초 멈춤 습관
- [ ] 터미널을 화면에 띄울 경우: 이메일·토큰·홈 경로(`/Users/...`)가 보이지 않는 위치로 스크롤

**말하기**

- [ ] 조용한 방, 마이크 20cm, 첫 3초는 무음으로 두었다가 0:00에 시작(편집 여유)
- [ ] 아래 대본을 한 번 소리 내어 읽고 **문장이 길면 둘로 끊어서** 말하기 (속도는 1초에 4~5음절)
