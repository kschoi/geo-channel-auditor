# 5분 시연 대본 — Geo Channel Auditor v0.2.0

5분을 목표로 한 구성입니다. 이미지 생성까지 현장에서 마치는 시간을 보장하지 않습니다. API 대기에 따라 실제 길이는 달라질 수 있습니다.

> 라이너 .EXE-THON 제출용 · 팀 클로클립 · 최경선
> 저장소: https://github.com/kschoi/geo-channel-auditor

`⟨ ⟩`는 촬영 때 나온 값으로 채웁니다. 숫자·표기 차이·메뉴를 미리 정하지 않습니다.

## 촬영 전 준비

```bash
git clone https://github.com/kschoi/geo-channel-auditor.git
cd geo-channel-auditor
uv sync --extra dev
cp .env.example .env
# .env에 LINER_API_KEY 설정. 키 입력 화면은 녹화하지 않습니다.
uv run pytest
uv run ruff check .
uv run uvicorn app.main:app --reload
```

- `http://127.0.0.1:8000`에서 실제 매장명·지역으로 실행합니다. `LIVE` 배지는 키 설정 표시이므로 API 성공 여부도 확인합니다.
- 실제 값·인용문·날짜·출처를 읽고 아래 대본의 빈칸을 채웁니다.
- 촬영 전에 앱의 Liner 이미지 생성을 실제로 실행하고 요청·결과를 확인합니다. 사전 생성 결과를 쓰면 `사전에 Liner API로 생성한 실제 결과`라고 표시합니다.
- 별도 Codex 이미지 생성 도구로 만든 시안은 앱의 Liner 실연동 증거가 아닙니다. 사용한다면 `외부 도구로 만든 연출 시안`으로 구분합니다.
- 실제 매장 사진을 보여줄 때는 직접 촬영했거나 사용 권한이 있는 사진 3장을 준비합니다. JPG·PNG·WebP, 파일당 15MB·4천만 화소·긴 변 12,000px 이내여야 합니다.
- 대기를 줄여 편집하면 화면에 `대기 구간 편집`을 표시합니다. 실행 시간을 임의로 연출하지 않습니다.
- 데스크톱과 390px 모바일, 저장한 PNG를 확인합니다. 알림·키·비공개 자료는 녹화 범위에서 제외합니다.

## 6장면 진행

| 목표 구간 | 화면 조작 | 내레이션 |
| --- | --- | --- |
| **0:00–0:25 · 문제** | 첫 화면과 통합 검색창 | 같은 매장을 찾아도 사이트마다 영업시간이나 가격이 다를 때가 있습니다. 어느 문장을 보고 무엇을 다시 확인해야 할까요? Geo Channel Auditor는 흩어진 매장 정보를 근거 문장과 함께 정리합니다. |
| **0:25–1:40 · 실제 검색** | `⟨지역·매장명·업종⟩` 입력 후 검색. 대기 중 수집 방식 설명 | 오늘은 ⟨매장명·지역⟩을 검색합니다. Liner Search와 Search Agent가 제공한 제목·요약·발췌를 모읍니다. Router가 값과 인용문을 추출하면 서버가 인용문과 값이 제공된 문자열 안에 있는지 대조합니다. |
| **1:40–2:45 · 근거와 확인할 일** | `항목별 확인 내용`에서 실제 근거 1~2개를 펼침. 날짜 비교 후 `먼저 확인할 일`의 근거로 이동 | 주소·시간·가격·주차·예약·메뉴 언급, 여섯 항목입니다. ⟨값⟩ 옆에 ⟨짧은 인용문⟩과 ⟨게시일·자료 종류⟩가 붙어 있습니다. ⟨실제 비교 결과 또는 날짜 상태⟩를 보고, 먼저 ⟨실제 확인할 일⟩을 확인하면 됩니다. |
| **2:45–3:40 · 카드·이미지 생성** | `문구 3장 만들기` → 원고 확인 → `AI 이미지 3장 만들기`. 대기 중 근거·출처 설명 | Liner가 한국어 문구·캡션과 영어 연출안을 쓰고, 이미지 API가 배경을 만듭니다. 같은 Liner 키를 사용합니다. 검색 분석은 원문 전체·운영 주체·현재 사실을 인증하지 않으며, 자료에서 못 찾았다고 서비스가 없다는 뜻도 아닙니다. 생성 그림도 AI 연출 시안입니다. 실제 메뉴 판매와 최종 문구는 매장에서 확인해야 합니다. |
| **3:40–4:40 · 이미지·문구 편집과 저장** | 완료된 실제 생성 결과 또는 표시한 사전 결과 → 구도·문구 위치·분위기·문구 수정 → PNG 저장·열기 | ⟨현재 완료된 결과 / 사전에 Liner API로 생성한 결과⟩입니다. 구도를 맞추고 ⟨확인한 문구⟩로 고쳐 1080×1350 PNG로 저장합니다. 생성 이미지에는 `AI 연출 이미지` 표시가 남습니다. 실제 매장 사진으로 바꿀 수도 있고, 직접 넣은 사진은 서버로 보내지 않습니다. |
| **4:40–5:00 · 가치** | 저장한 카드와 검토 화면, 저장소 표시 | 검색한 정보의 근거를 읽고, 확인할 일을 고른 뒤, 이미지와 문구를 직접 고친 카드까지 만듭니다. 매장 정보를 다시 찾고 홍보 문구로 옮기는 수고를 줄이는 도구입니다. 실행 방법과 검증 코드는 저장소에 담았습니다. |

### 3번 장면은 실제 결과에 맞춰 말하기

- `표기가 다름`이 있으면 같은 시간 조건 또는 같은 메뉴 가격의 값·날짜를 나란히 보여줍니다. “표기가 달라 적용 조건을 확인할 후보입니다”라고 설명합니다. 어느 쪽이 사실인지 확정하지 않습니다.
- 날짜 미상·과거 기록·추측 표시가 있으면 실제 표시 하나를 읽습니다. 없으면 이 설명은 생략합니다.
- 확인할 일이 없으면 “추가 확인 항목은 없습니다. 근거와 날짜를 살펴보겠습니다”라고 말합니다. 근거가 없는 항목은 “이번 자료에서 못 찾았습니다”라고 설명합니다.
- 실제 차이가 없으면 비교 장면을 생략합니다. 사례를 꾸미거나 다른 지점 자료를 끼워 넣지 않습니다.

### 이미지 생성이 끝나지 않았을 때

- 현장 생성은 대기 상태를 보여주고, 3번 장면의 근거·날짜·출처 설명을 이어갑니다. 완료됐을 때만 PNG 결과를 보여줍니다.
- 시간이 부족하면 사전 실제 호출 결과로 전환했다고 밝히거나, 대기 중인 장면에서 마칩니다. 외부 시안으로 성공을 연출하지 않습니다.
- 연결을 끊어도 생성과 과금은 계속될 수 있습니다. `기다리기 중단`은 화면 대기만 멈춥니다. 새 생성 요청보다 `결과 다시 확인`으로 같은 화면의 기존 작업을 먼저 확인합니다. 자동 재생성은 하지 않습니다.
- 결과 확인 중에는 새로고침하거나 서버를 재시작하지 않습니다. 새로고침 뒤 작업 복구는 지원하지 않습니다.
- Liner 공식 문서는 이미지 요청이 약 7분까지 걸릴 수 있다고 안내합니다. 이 대본의 시간 배분은 발표 목표입니다. [공식 문서](https://liner.com/developers/docs/liner-model-api-images)

## 촬영자 참고 — 화면 밖에서 확인

아래 내용은 대본을 그대로 읽는 부분이 아니라, 결과를 해석하고 제출 영상을 점검하는 기준입니다.

| 확인 대상 | 기준 |
| --- | --- |
| 날짜와 표기 비교 | 날짜는 API 제공값입니다. 날짜 미상·1년 넘은 자료·추측을 구분합니다. 시간은 항목과 요일 범위, 가격은 같은 메뉴명끼리 비교합니다. 옵션·시점까지 완전히 해석하지 못하므로 최근 자료를 정답으로 단정하지 않습니다. |
| 출처와 운영자 | `자세히 보기`에서 자료 구성·출처·API 로그를 확인합니다. 비중은 이번 URL의 도메인 종류이며 운영 주체는 모두 미확인입니다. 채널 추천 순위나 다른 AI의 인용·검색량을 측정한 값이 아닙니다. |
| 카드 입력과 출처 | 검색 요약 전체나 기존 생성 원고를 다시 사용하지 않습니다. 날짜 미상·과거 자료의 메뉴명은 남을 수 있습니다. 메뉴 언급을 대표메뉴·인기로 설명하지 않습니다. `참고 출처` 링크와 캡션은 PNG에 포함되지 않습니다. |
| 이미지 생성 | AI가 재료나 음식 형태를 틀리게 그릴 수 있으므로 생성 결과를 직접 확인합니다. 같은 Liner 키로 Images API를 호출합니다. 프롬프트는 Liner로 보내며 생성 그림은 실제 매장·음식을 인증하지 않습니다. 화면과 PNG의 AI 표시를 확인합니다. 크레딧 사용을 안내하고 자동 재생성하지 않습니다. |
| 사진과 편집 | `1장 사진 넣기`로 사진을 넣습니다. 추가한 사진은 `사진 바꾸기`·`사진 빼기`로 교체하거나 뺄 수 있습니다. `사진 위치 조절`은 좌우·위아래, `문구 위치`는 왼쪽 아래·왼쪽 위·가운데입니다. `사진 분위기`는 자연광·따뜻하게·차분하게입니다. `사진 연출안`은 재료·형태·빛 조건을 구체적으로 적은 영어 지시문이며 `연출안 복사`로 가져갑니다. |
| 저장 | 제목 40자·본문 180자·캡션 1500자 이내입니다. AI 이미지나 로컬 사진이 없는 장은 PNG 저장이 비활성입니다. `1장 PNG 저장`~`3장 PNG 저장`으로 저장하고 사진 구도·한글·줄바꿈·수정 문구·크기를 확인합니다. |
| 문구 재생성 | 원고를 새로 만들려면 `문구 다시 만들기`를 누릅니다. 직접 문구를 고치는 편집과 구분합니다. |
| 키와 호출 | 일회성 키로 분석했다면 카드 생성 전에 다시 입력합니다. 원고 생성은 Router 추가 호출, 이미지 생성은 장별 Images API 호출입니다. 로컬 사진 추가·편집·PNG 저장은 API를 호출하지 않습니다. |

## 오류가 나면

- 매장명이 빠졌거나 다른 지점 자료라면 이름·지점·지역을 보완합니다.
- 키 오류·API 실패·시간 초과는 실제 오류 안내를 보여주고 원인을 해결한 뒤 재시도합니다. 가상 결과로 성공을 연출하지 않습니다.
- 자료 문자열과 맞지 않는 추출값은 제외됩니다. 다른 근거가 없다면 못 찾은 상태로 설명합니다.
- 이미지 생성 오류는 기존 작업의 결과부터 재확인합니다. 새 생성은 추가 비용이 생길 수 있습니다.
- 로컬 사진 형식·용량·크기 오류는 조건에 맞는 파일로 바꿉니다. 카드 생성·저장 오류는 파일까지 확인한 뒤 재촬영합니다.

## 제출 전 확인

- [ ] 실제 매장과 출처가 맞고, 대본의 빈칸을 실제 결과로 채웠습니다.
- [ ] 값·인용문·날짜·자료 종류와 확인할 일을 화면에서 보여줬습니다.
- [ ] 카드 생성 장면에서 분석 범위와 발행 전 확인 사항을 설명했습니다.
- [ ] 실제 Liner 이미지 호출 결과와 외부 도구 시안을 구분했습니다.
- [ ] 구도 조절·문구 수정·PNG 저장과 생성 이미지의 AI 표시를 보여줬습니다.
- [ ] 종합 점수·고정 결핍 3건·채널 순위·자동 발행을 현재 기능으로 설명하지 않았습니다.
- [ ] 키·비공개 자료가 보이지 않으며 대기 편집 여부를 표시했습니다.
- [ ] 최종 영상 길이·형식은 제출 요건에 맞췄습니다.

설명란 예시:

> 실제 매장 검색 자료를 값·근거 문장·날짜로 정리하고, 사람이 확인할 일과 편집할 카드뉴스로 연결합니다. 제공된 문자열을 대조하는 도구이며 현재 매장 사실을 인증하지 않습니다. Liner가 문구·연출안과 AI 배경 이미지를 만들고, 브라우저에서 편집해 PNG로 저장합니다. 생성 그림은 AI 연출 시안이며 실제 매장 사진이 아닙니다. 직접 준비한 로컬 사진도 사용할 수 있습니다. 최종 문구와 메뉴 판매 여부는 발행 전에 확인합니다.
