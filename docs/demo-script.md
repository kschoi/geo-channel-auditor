매장 인사이트는 흩어진 후기를 읽고, 동네의 인구와 함께 살펴보면서, 다음에 해볼 일을 찾는 도구입니다.

이번에는 찾은 전체 기간을 선택합니다. 최근 흐름만 보고 싶다면, 삼 개월이나 일 년으로 줄일 수도 있습니다.

고객 인식 살펴보기를 누르면 공개 자료를 찾기 시작합니다. 같은 매장인지 확인하고, 겹치는 문서는 하나로 모읍니다.

숫자로 비교하기를 펼치면, 같은 내용을 표로도 확인할 수 있습니다.

## 녹화·편집 기준

- 실제 앱 화면을 16:9로 녹화해 1920×1080을 가득 채운다. 별도 상단 제목·장 제목 띠·빈 바깥 프레임은 넣지 않는다.
- 사용자가 설정한 **로컬 Chatterbox 여성 음성**으로 내레이션을 만든다. 음성·화면 합성과 최종 인코딩은 FFmpeg로 처리한다.
- 흰 자막을 시연 화면 위에 얹는다. 검정 배경은 65% 불투명도로, 각 자막의 텍스트 너비와 여백만 감싼다. 전체 폭의 자막 띠는 넣지 않는다.
- 자막은 중요한 숫자·버튼·인용문을 가리지 않게 배치한다. 한 번에 읽기 어려운 긴 문장은 나눈다.
- API 대기를 줄인 편집은 설명문에 기록한다. 결과를 다른 실행 값이나 임의 데이터로 교체하지 않는다.
- 인구는 실제 공식 스냅샷, 가상 반응은 명시된 합성 실험이라는 화면 구분을 유지한다. 합성 인물의 반응을 실제 손님의 후기처럼 연출하지 않는다.
- 빈 회색 화면을 길게 보여주지 않는다. 근거 카드·인구 분포·취향 사례처럼 실제 읽을 내용이 있는 화면으로 진행한다. 이미지가 쓰이면 실제 매장 사진인지 시안인지 출처와 성격을 유지한다.
- 카드뉴스는 이동 경로만 소개한다. 앱 자체가 시연 영상이나 숏폼을 생성한다고 설명하지 않는다.

## 최종 검수

- 실제 검색·인구 선택·가상 반응 실험을 실행하고 녹화했다. Liner 호출은 검색·분석 12회, 가상 반응 1회 모두 성공했다.
- Chatterbox 음성 37문장을 속도 변경 없이 사용했다. 로컬 음성 인식 검사에서 누락·반복이 없었다.
- MP4 1920×1080, H.264/AAC, 30fps, 9,000프레임, 300초. 영상 디코딩 오류는 0건이다.
- 자막 64개는 흰색 42px, 최대 2줄이다. 검정 65% 배경에 좌우 18px·상하 10px 여백을 두고 아래에서 72px 띄웠다.
- 실제 인구의 기준일과 가상 실험 표시를 유지했다. 390px 모바일에서도 표·인물 선택과 가로 넘침을 확인했다.
