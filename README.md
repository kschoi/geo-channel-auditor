# Geo Channel Auditor

> 라이너 .EXE-THON 출품작 · v0.2.0 · 팀 클로클립 · 최경선

**매장 검색 자료에서 방문 정보를 근거 문장과 함께 정리하고, 직접 확인할 일을 알려줍니다.**
`성수동 로우키 카페`처럼 지역·매장명·업종을 입력합니다. 확인 항목을 검토한 뒤 카드뉴스 3장의 문구·사진 연출안을 만듭니다. Liner로 AI 연출 이미지를 생성하거나 직접 준비한 매장 사진을 넣어, 편집한 카드를 PNG로 내려받을 수 있습니다.

## 실행

```bash
git clone https://github.com/kschoi/geo-channel-auditor.git
cd geo-channel-auditor
uv sync --extra dev
cp .env.example .env
# .env에 LINER_API_KEY 설정
uv run uvicorn app.main:app --reload
```

`http://127.0.0.1:8000`을 엽니다. `.env`는 Git에서 제외하며 앱 시작 시 읽습니다. `API 설정`의 일회성 키는 요청 후 입력칸을 비웁니다. 비워두면 서버 키를 사용합니다.

`LIVE`는 키 설정 표시입니다. 호출 성공은 결과·API 로그로 확인합니다. 키 없음·API 실패·시간 초과는 오류로 알리고 가상 결과로 대체하지 않습니다. `/api/health?probe=true`는 잔액 API 호출 성공 여부만 확인하며 잔액 숫자는 반환하지 않습니다.

## 분석 흐름

1. **Search·Search Agent 수집:** 매장명·지역이 맞는 공개 검색 자료와 출처를 모읍니다. Search Agent가 작성한 답변 자체는 사실 근거로 쓰지 않습니다.
2. **Router 추출:** 검색 결과 제목·요약, URL이 연결된 Agent 제공 발췌에서 항목별 값과 인용 문장을 추출합니다.
3. **서버 규칙 대조:** 인용문이 제공된 자료 문자열에 그대로 포함되는지, 값이 인용문 안에 있는지 확인합니다. 출처 연결·형식이 맞지 않는 추출값은 제외합니다.
4. **확인할 일 정리:** 표기 차이, 오래된 기록, 날짜 미상, 추측, 근거를 못 찾은 항목을 구분합니다. 필요한 확인 항목만 만들며 화면에서는 최대 3건을 먼저 보여줍니다.
5. **카드뉴스:** 매장·지역과 자료에 언급된 메뉴명을 담은 정제 자료로 짧은 문구·사진 연출안·문구 위치를 제안합니다. Liner 이미지 생성 또는 직접 준비한 사진을 선택하고 문구·배치를 고쳐 PNG로 저장합니다.

현재 LIVE 결과에는 종합 점수, 고정된 결핍 3건, URL 비중순 채널 추천, 기존 3채널 원고 탭을 제공하지 않습니다.

## 6개 항목과 근거

| 항목 | 정리하는 내용 |
| --- | --- |
| 주소 | 자료에 적힌 주소 표현 |
| 영업시간 | 영업시간·휴게시간·주문 마감, 적힌 요일·적용 범위 |
| 메뉴 가격 | 메뉴별 가격. 과거 결제액은 현재 가격표와 구분 |
| 주차 | 주차에 관한 서술 |
| 예약 | 예약·웨이팅·대기 관련 서술 |
| 메뉴 언급 | 자료에 등장한 메뉴명. 현재 판매·대표메뉴·인기 여부는 미확인 |

각 근거에는 **값, 그대로 가져온 인용 문장, 출처 링크, API가 제공한 게시일, 자료 종류**를 연결합니다. 자료 종류는 `검색 결과 제목`, `검색 결과 요약`, `Search Agent 제공 발췌`입니다.

- **자료에 있음:** 근거 문장을 찾았다는 뜻입니다. 현재 운영 정보로 확정한 상태는 아닙니다.
- **표기가 다름:** 영업시간은 같은 시간 종류·요일 범위끼리, 가격은 같은 메뉴명끼리 표기 차이를 비교합니다. 어느 값이 맞는지, 실제 사실이 충돌하는지는 판단하지 않습니다.
- **확인 필요:** 날짜 미상, 게시 후 1년 초과, 과거 기록·결제액, 추측 표현을 구분해 표시합니다. 게시일은 API 제공값이며 최신성 보장이 아닙니다.
- **자료에서 못 찾음:** 이번에 읽은 문자열에서 근거를 추출하지 못했다는 뜻입니다. 해당 서비스나 정보가 매장에 없다는 뜻은 아닙니다.

시간의 요일 미기재와 `매일`은 일반 운영시간 후보로 묶습니다. 메뉴 가격의 옵션·시점까지 완전히 해석하는 비교가 아니므로, **표기 차이는 운영자에게 확인할 후보**로 봐야 합니다. 주소 축약·주차장 이름·메뉴명 차이를 문자열만으로 충돌 판정하지 않습니다.

## 화면 읽기

`매장 검색 자료 검토`에서 대상·자료 수·검토 시각·범위를 봅니다. `먼저 확인할 일`의 `근거 보기`를 누르면 `항목별 확인 내용`으로 이동합니다. 항목을 펼쳐 값·인용문·날짜·출처를 비교합니다.

`자세히 보기 (출처 · API 로그)`에는 전체 출처, API 기록, `이번에 찾은 자료 구성`이 있습니다. 자료 구성은 URL을 중복 제거한 도메인별 비중입니다. 블로그·카페, 플레이스, SNS, 예약·판매 플랫폼, 후기·지역정보 플랫폼, 미분류로 나눕니다.

**도메인 종류와 운영 주체는 별개입니다.** 예약 플랫폼이나 블로그에 있다는 이유로 매장 공식 자료로 취급하지 않습니다. 현재 모든 출처의 운영 주체는 미확인입니다. 자료 비중으로 추천 채널 순위를 만들지 않으며, 다른 AI 서비스의 인용·검색량·클릭률·홍보 성과도 측정하지 않습니다.

## 카드뉴스 만들기

1. 항목별 근거와 현재 매장 정보를 확인한 뒤 `문구 3장 만들기`를 누릅니다. Liner Router가 한국어 문구·캡션, 영어 사진 연출안, 문구 위치를 제안합니다. 다시 생성하려면 `문구 다시 만들기`를 누릅니다.
2. 제목(최대 40자)·본문(180자)·게시글 캡션(1500자)을 검토·수정합니다. 메뉴 언급만으로 현재 판매나 대표메뉴가 확인된 것은 아니므로 발행 전에 확인합니다.
3. **Liner 이미지 생성:** `AI 이미지 3장 만들기`를 누르면 문구·연출 프롬프트를 Liner에 보내 3장을 개별 요청으로 병렬 생성합니다. 검색·문구 생성과 같은 `LINER_API_KEY`를 쓰며 추가 OpenAI 키는 필요 없습니다. 생성 그림은 **AI 연출 시안**이며 실제 매장·음식의 모습이나 현재 판매를 인증하지 않습니다. 편집 화면과 PNG에 `AI 연출 이미지` 표시를 남깁니다. 장별 `AI 이미지 만들기`도 가능합니다.
4. **직접 준비한 사진:** 각 장의 `사진 넣기`로 실제 매장 사진을 고를 수도 있습니다. JPG·PNG·WebP, 파일당 **15MB·4천만 화소·긴 변 12,000px 이하**를 지원합니다. 로컬 사진은 서버에 보내지 않고 브라우저 안에서 처리합니다.
5. `사진 위치 조절`로 구도를 맞추고, `문구 위치`와 `사진 분위기`를 고릅니다. 분위기는 자연광·따뜻하게·차분하게입니다. 이미지가 화면을 꽉 채우고 그 위에 글자를 얹습니다.
6. `1장 PNG 저장`~`3장 PNG 저장`으로 **1080×1350 PNG**를 각각 내려받습니다. Canvas가 원본 이미지를 이 출력 크기에 맞춥니다. 이미지가 없는 장은 저장할 수 없습니다. `사진 바꾸기`·`사진 빼기`로 교체하거나 뺄 수 있습니다.

`사진 연출안`은 이미지 모델에 보낼 영어 지시문입니다. 재료·음식 형태를 구체적으로 쓰고, 빛·색감 조건은 세 장마다 반복해 전달합니다. 접힌 영역에서 읽고 복사할 수 있습니다. 이미지 생성은 별도 버튼을 눌렀을 때만 시작합니다. AI 시안의 음식·간판·공간을 실제 매장 모습으로 소개하지 않습니다. `참고 출처`와 캡션은 편집 화면에 있으며 PNG에는 넣지 않습니다.

카드 입력에는 검색 요약 전체나 기존 생성 원고를 다시 넣지 않습니다. 매장·지역 연결과 추측으로 분류되지 않은 메뉴 언급을 정제해 사용합니다. 날짜 미상·과거 자료의 메뉴명도 남을 수 있어 현재 판매 확인이 필요합니다. AI가 재료나 음식 형태를 틀리게 그릴 수 있으므로 발행 전에 생성 결과를 직접 확인합니다.

문구·연출안은 **Liner Router**, AI 배경 이미지는 **Liner Images API**, 사진 배치·글자 합성·PNG 출력은 **브라우저 Canvas**가 담당합니다. 동영상 제작이나 SNS 자동 발행 기능은 없습니다. 일회성 키로 분석했다면 후속 생성 요청 전에 다시 입력합니다.

### 생성 시간·크레딧·재확인

이미지 생성은 Liner 크레딧을 사용합니다. 연결을 끊어도 이미 시작한 생성은 계속되고 과금됩니다. 다시 생성하면 새 요청 비용이 생길 수 있습니다.

`기다리기 중단`은 화면의 대기만 멈춥니다. 앱은 자동으로 재생성하지 않으며, `결과 다시 확인`으로 같은 화면에 남아 있는 요청의 결과를 조회합니다. 생성 중 직접 넣은 사진은 새 결과로 덮어쓰지 않고 `생성 이미지 적용`으로 바꿀 수 있습니다.

작업과 결과는 임시 보관합니다. 새로고침하면 화면의 요청 번호를 잃고, 서버를 재시작하면 보관된 작업·결과가 사라집니다. 새로고침 뒤 복구나 영구 저장은 지원하지 않습니다.

공식 문서상 요청은 약 7분까지 걸릴 수 있어 5분 시연 안에 생성을 마친다고 보장하지 않습니다. [Liner Images 공식 문서](https://liner.com/developers/docs/liner-model-api-images)

`POST /api/cards`는 원고용 Router 추가 1회 호출입니다. 카드 3장·제목·본문·출처·연출안·문구 위치 형식과 제공된 URL 사용 여부를 검사합니다. 문구의 사실을 자동 인증하지 않습니다. 이미지 생성은 별도 호출이며, 로컬 사진 추가·문구 편집·PNG 저장은 API를 호출하지 않습니다.

## API와 검증

| API | 역할 |
| --- | --- |
| `POST /tools/search/web` | 공개 검색 자료 수집 (`country_code: kr`, `lang: ko`) |
| `POST /agents/search` | 참고 출처·연결된 발췌 수집. 생성 답변은 사실 근거에서 제외 |
| `POST /chat/completions` | `liner-gpt-router`로 항목별 관찰 추출. 카드뉴스는 별도 호출로 문구·사진 연출안 생성 |
| `POST /images/generations` | `qwen/qwen-image-2.1-turbo`로 장별 이미지 생성 (`n: 1`, `resolution: 1K`, `aspect_ratio: 4:5`) |
| `GET /credits/balance` | 연결 상태 확인 |

Base URL은 `https://platform.liner.com/api/v1`, 인증은 `x-api-key`입니다. 호출 횟수·소요 시간은 실제 API 로그를 확인합니다. 검토 범위는 제공된 문자열의 일부이며 길이·수량 제한이 있어 모든 내용을 읽었다고 보장하지 않습니다.

```bash
uv run pytest
uv run ruff check .
# Node.js가 있는 환경: 사진 편집기 회귀 검사
node tests/test_photo_editor.cjs
```

**실행 확인 기록(2026-11-18):** 산본 디델리 검색 자료 31건을 바탕으로 Router의 한국어 문구·영어 연출안 3개를 만들고, Liner 이미지 3장을 생성했습니다. 제목·본문 6개 입력칸 수정과 자연광 톤 변경 후 PNG 3장을 내려받아 모두 1080×1350인 것을 확인했습니다.

- 데스크톱 1280px에서 1·2장, 모바일 390px에서 3장을 저장했습니다. 두 화면 모두 가로 넘침이 없었고 브라우저 콘솔 오류는 0건이었습니다.
- `qwen/qwen-image-2.1-turbo` 이미지 요청 3건은 모두 HTTP 200으로 완료됐습니다. 비용은 장당 0.0184 USD, 합계 0.0552 USD였습니다. 이번 실행의 관측값이며 고정 가격을 보장하지 않습니다.
- 앞선 실행에서는 2장의 대기를 중단한 뒤 같은 요청을 GET으로 재조회했습니다. 생성 POST는 3회였고 자동 재생성은 없었습니다.
- 로컬 사진 업로드는 모의 검증까지 통과했습니다. 이번 실제 브라우저 파일 선택·업로드 완료는 확인하지 못했습니다.

자동 검증과 실제 LIVE 실행은 구분합니다. 제출 전 매장 일치, 값·인용문 연결, 조건별 표기 비교, 날짜 표시, 데스크톱·390px 모바일, 실제 이미지 API 응답·AI 표시·로컬 사진 추가·카드 수정·PNG 파일을 확인합니다. 가상 픽스처는 명시적으로 선택한 내부 테스트용이며 실행 서버에 테스트 설정을 적용하지 않습니다.

## 한계와 데이터

- **서버 검증은 문자열·규칙 대조입니다.** 원문 페이지 전체, 현장 상태, 공식 운영 주체, 현재 영업 사실을 검증한 것은 아닙니다. 정확히 인용돼도 자료가 오래됐거나 작성자가 틀렸을 수 있습니다.
- **매장 일치는 표현 대조입니다.** 상호는 제목·URL, 지역은 제목·요약·URL에서 찾습니다. 동명이점·다른 지점이 섞이거나 관련 자료가 제외될 수 있습니다.
- **공개 검색에 없는 정보는 확인 대상입니다.** 비공개 SNS나 미색인 자료를 포함한 전 채널 조사가 아닙니다.
- 키는 환경변수·Git 제외 `.env`·일회성 입력으로 받고 응답·로그에 포함하지 않도록 처리합니다. 비공개 고객 자료와 ClawClip 사내 데이터를 쓰지 않는 독립 프로젝트입니다.
- 스타일은 로컬 CSS, Pretendard는 CDN을 사용하며 실패하면 시스템 글꼴을 사용합니다.
