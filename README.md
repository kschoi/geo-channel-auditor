# Geo Channel Auditor · 고객 인식 분석

> Liner .EXE-THON · 팀 클로클립 · 최경선

**“고객은 우리 매장을 어떻게 볼까?” 공개 후기와 웹문서에서 긍정·부정의 이유를 찾고 경쟁점과 비교합니다.**

`산본 디델리 분식`처럼 지역·실제 매장명을 입력합니다. 경쟁점을 최대 2개 넣으면 같은 기간과 검색 예산으로 자료를 모읍니다. 품질·서비스·가격 대비 가치·분위기·접근성·대기·청결을 원문 근거와 함께 읽고, 먼저 할 일을 정합니다.

## 실행

```bash
uv sync --frozen --extra dev
cp .env.example .env
# .env에 LINER_API_KEY 설정
uv run uvicorn app.main:app --host 127.0.0.1 --port 8765
```

[로컬 앱](http://127.0.0.1:8765)에서 시작합니다. `.env`는 Git에서 제외합니다. 일회성 키는 접힌 API 설정에서 입력하며 브라우저에 저장하지 않습니다.

## 무엇을 보여주나요?

- **고객 인식:** 확인한 기간 내 후기 문서의 긍정·부정·혼합·중립 건수. 같은 문서를 반복해서 세지 않습니다.
- **항목별 비교:** 사각형 빗금 밀도와 숫자 표로 부정 근거의 비율을 읽습니다. 칸마다 실제 자료 수를 표시합니다.
- **원문 근거:** 인용문·출처·게시일로 판단 이유를 확인합니다. 후기와 홍보·기사·성격 미확인 자료를 구분합니다.
- **성별·연령:** 공개 리뷰에서 확인되지 않으므로 미확인으로 표시합니다. 이름·사진·말투로 추정하지 않습니다.
- **상권 자료:** 공식 공개 문서에 지역·기간·단위·교차값이 명시된 경우만 수치를 표시합니다. 상권 인구를 매장 고객 수로 사용하지 않습니다.
- **행동 제안:** 대상 매장 근거에 연결된 확인·개선 제안입니다. 자료 부족 시 제안을 꾸며내지 않습니다.

숫자는 **이번 검색에서 확보한 문서**를 나타냅니다. 전체 고객 만족도, 사이트 전체 리뷰, 다른 AI의 인용률을 측정하지 않습니다. 표본이 작거나 출처 구성이 다르면 경쟁점 비교 한계를 표시하며 순위를 매기지 않습니다. 감정·글의 성격은 AI 해석이며, 인용 일치 검사만으로 그 해석을 인증하지 않습니다.

## 분석 흐름

1. Liner Search·Search Agent로 실제 매장 공개 자료 수집. 생성된 Agent 답변 자체는 사실 근거로 쓰지 않습니다.
2. Liner Router가 항목·감정·글의 성격과 원문 인용을 추출합니다.
3. 서버가 출처 연결·인용 일치·게시일·중복을 검사합니다. 날짜 미상은 주 비율에서 분리합니다.
4. 근거가 있는 문서만 집계해 비교와 행동 제안으로 연결합니다.

대상 포함 최대 3개 매장에 각 Search 3회·Agent 1회, 공식 상권 검색 2회, 근거가 있으면 Router 최대 2회입니다. 카드뉴스·이미지 생성은 별도 요청입니다. 실제 호출·실패 기록은 결과의 접힌 상세 영역에서 볼 수 있습니다.

상권 통계 API의 지역별 전수 연동은 아직 없습니다. 별도 공공데이터 키 없이 찾을 수 있는 공식 공개 문서에서만 값을 확인하므로, 필요한 지역·기간의 수치가 없으면 미확인으로 남습니다. 전체 설계와 제약은 [고객 인식 스펙](docs/customer-perception-spec.md)에 담았습니다.

## 기존 매장 정보 검토·카드뉴스

[/source-audit](http://127.0.0.1:8765/source-audit)에서 주소·시간·가격·주차·예약·메뉴 근거를 검토하고 카드뉴스 3장을 제작·수정·다운로드할 수 있습니다. 새 분석에서 대상 매장 검색어만 넘기므로 경쟁점 자료가 원고에 섞이지 않습니다. 새 검토와 생성은 사용자가 버튼을 눌러 시작합니다.

문구·사진 연출안은 Liner Router, AI 배경은 Liner Images API, 사진 배치·한글 합성·1080×1350 PNG 출력은 브라우저 Canvas가 담당합니다. 같은 Liner 키를 사용합니다. 생성 이미지는 AI 연출 시안이며 실제 매장 사진이 아닙니다. [카드뉴스 사용법과 한계](docs/source-audit.md)를 참고하세요.

```bash
uv run pytest

```

단위·API 검사는 외부 호출 없이 오류, 원문 조작, 중복, 기간, 미확인값, 키 보호, 취소를 검증합니다. 실제 Liner 호출과 데스크톱·390px 모바일은 별도로 확인합니다. [5분 시연 흐름](docs/demo-script.md)과 [제출 기획서](docs/Geo_Channel_Auditor_기획서.pdf)는 새 고객 인식 흐름을 기준으로 작성합니다.

## API

- `POST /api/perception`, `/api/perception/stream`: 고객 인식·경쟁점·공개 상권 근거
- `POST /api/audit`, `/api/audit/stream`: 기존 6개 방문 정보 검토
- `POST /api/cards`: 카드뉴스 문구·연출안
- `POST /api/card-images`, `GET /api/card-images/{request_id}`: Liner 이미지 생성·결과 조회
- `GET /api/health`: 키 설정 여부. `probe=true`는 잔액 API 연결 검사

오류를 가상 결과로 대체하지 않습니다. 실제 API 비용과 처리 시간은 Liner 상태에 따릅니다. 앱 자체에는 동영상 생성이나 SNS 자동 발행 기능이 없으며, 제출 시연 영상은 완성 앱을 별도로 녹화합니다.
