# Geo Channel Auditor

> 라이너 .EXE-THON 출품작 · v0.2.0 · 팀 클로클립 · 최경선

**실제 매장을 검색해 채널을 진단하고, 문구를 고쳐 PNG로 받을 수 있는 카드뉴스 3장을 만듭니다.**
`성수동 로우키 카페`처럼 지역·매장명·업종을 한 줄로 입력합니다. Liner Search로 공개 자료를 찾고, Search Agent로 고객이 확인할 정보를 정리한 뒤, Router가 채널별 제안을 만듭니다. 이어서 같은 검색 근거로 카드뉴스 3장과 게시물 캡션을 생성하고, 문구·배경을 고른 뒤 PNG로 내려받습니다.

API 키가 없거나 검색·생성에 실패하면 오류를 안내합니다. 결과를 가상 매장·가상 출처·데모 원고로 대체하지 않습니다.

## 실행

```bash
git clone https://github.com/kschoi/geo-channel-auditor.git
cd geo-channel-auditor
uv sync --extra dev
cp .env.example .env
# .env에 LINER_API_KEY 설정
uv run uvicorn app.main:app --reload
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. `.env`는 Git에서 제외하며 앱 시작 시 읽습니다.
`API 설정`에 키를 입력하면 해당 요청에만 사용하고 입력칸을 비웁니다. 비워두면 서버 키를 사용합니다.

`LIVE`는 키 설정 표시입니다. 성공 여부는 결과와 API 로그에서 확인합니다. `/api/health?probe=true`는 잔액 API 호출 성공 여부를 확인하며, 잔액 숫자는 반환하지 않습니다.

## 실제 매장으로 진단하기

- 빠른 예시는 **성수 로우키 · 서울대입구 우태하피부과 · 홍대 테이스티버거**입니다. 코드에는 검색을 시작할 이름·상권·업종을 담으며, 가격·영업시간·소개 문구를 미리 만들어 넣지 않습니다.
- 직접 검색할 때도 지역·업종·매장명 또는 지점을 함께 입력합니다. 매장명 없이 업종만 넣으면 입력 보완 오류로 중단합니다. 같은 이름의 다른 지점이 섞이지 않도록 지역을 구체적으로 적습니다.
- 기존 채널 글이 있으면 `+ 채널 글 직접 넣기`에서 추가합니다. 실제 공개 검색 근거와 함께 참고합니다.
- 매장명과 지역이 맞는 공개 검색 근거를 찾지 못하면 제안을 만들지 않습니다. 검색어를 보완해 다시 시도합니다.
- 예시 칩을 누르면 이전 고급 입력을 비우고 새 매장을 검색합니다. 세부 출처·API 로그는 `자세히 보기`에 접혀 있습니다.

| 검색한 정보로 카드뉴스까지 | 검색 근거로 문구 생성 → 제목·본문 수정 → 배경 선택 → 1080×1350 PNG 개별 다운로드 |

모바일에서는 한 열로 읽습니다. API 실패·시간 초과·근거 부족은 성공 결과와 구분해 안내합니다.

## 카드뉴스 만들기

1. 실제 매장 진단을 마친 뒤 `카드뉴스 만들기`를 누릅니다.
2. 검색 근거로 생성된 3장의 제목·본문과 게시물 캡션을 확인합니다.
3. 각 장의 제목(40자)·본문(180자)을 고치고 `카드 색상`에서 블루·민트·차콜을 고릅니다. 게시글 캡션(1500자)도 수정·복사할 수 있습니다. 새 사실은 출처와 대조합니다.
4. `1장 PNG 저장`부터 `3장 PNG 저장`까지 눌러 **1080×1350 PNG**를 장별로 내려받습니다. 파일을 열어 한글·줄바꿈·문구를 확인한 뒤 사용합니다.

각 장의 `참고 출처`에서 링크를 확인합니다. 출처 링크와 게시글 캡션은 PNG에 넣지 않습니다. 일회성 키로 진단했다면 카드 생성 전에 `API 설정`에 키를 다시 입력해야 합니다.

문구는 **Liner Router**, 화면 구성과 PNG 출력은 **브라우저 Canvas**가 담당합니다. 이미지 생성 API로 사진을 만드는 방식이 아닙니다. 촬영 사진·동영상 제작이나 SNS 자동 발행은 제공하지 않습니다.

`POST /api/cards`는 진단에서 얻은 매장명·지역·검색 근거와 참고 문구를 받아 Router를 1회 더 호출합니다. 각 카드의 `source_urls`는 요청으로 전달한 관련 출처에 포함돼야 합니다. 제목·본문·출처가 빠지거나 3장이 아니면 오류로 처리합니다. 잘못된 결과를 고정 예시로 대체하지 않습니다. 생성 시간은 API 상태에 따라 달라지며, 시간 초과 시 오류를 안내합니다.

## Liner API 사용 범위

| API | 역할 |
| --- | --- |
| `POST /tools/search/web` | 상권·업종 질문과 매장명·지역 검색으로 공개 자료 수집 (`country_code: kr`, `lang: ko`) |
| `POST /agents/search` | 고객이 방문 전에 확인할 정보·질문 요약과 인용 출처 반환 |
| `POST /chat/completions` | `liner-gpt-router`, `response_format: json_object`로 진단·채널 추천·원고 생성. 카드뉴스 생성 시 1회 추가 호출 |
| `GET /credits/balance` | `/api/health?probe=true`에서 API 연결 상태 확인 |

Base URL은 `https://platform.liner.com/api/v1`, 인증은 `x-api-key` 헤더입니다. 정상 진단은 채널 글이 80자 이상이면 5회(검색 3 + Agent 1 + Router 1), 80자 미만이고 자동 수집이 켜져 있으면 7회 호출합니다. 카드뉴스를 만들면 Router 1회가 더해집니다. 문구 직접 편집·PNG 다운로드에는 API를 호출하지 않습니다. 실패하면 즉시 중단하므로 실제 호출 수는 더 적을 수 있습니다. 성공 여부와 소요 시간은 API 로그에서 확인합니다.

`citation_analysis`는 **Liner 검색 결과(매장 검색 포함)와 Search Agent 인용 출처를 합친 URL 비중**입니다. 같은 URL은 한 번만 셉니다. 블로그·플레이스·SNS·공식 웹·리뷰/언론 5개 채널과 미분류로 구분합니다. 모르는 도메인은 리뷰로 단정하지 않으며, 미분류는 우선 추천에서 제외합니다.

GPT·Perplexity·Gemini·Claude 등 다른 AI 서비스의 인용은 수집하지 않습니다. 실제 검색량·클릭률·답변별 인용 횟수·노출 순위를 측정한 값도 아닙니다.

## 데이터와 보안

- 실제 제안은 Liner API로 수집한 공개 자료와 사용자가 입력한 채널 글을 사용합니다. 검색 근거가 없는 가격·영업시간·서비스는 `[확인 필요]`로 표시하도록 생성 지침을 적용합니다. 결과의 사실 여부는 발행 전 다시 확인해야 합니다.
- 가상 픽스처는 명시적으로 선택한 내부 테스트에서만 사용합니다. 일반 웹 화면과 API 진단은 가상 결과로 전환하지 않습니다. 테스트용 환경 설정은 실행 서버에 적용하지 않습니다.
- 키는 환경변수·Git 제외 `.env`·요청의 일회성 입력으로 받습니다. 응답·로그·검증 오류에 키를 포함하지 않도록 처리합니다.
- ClawClip의 비공개 코드·비즈니스 로직·고객 자료를 사용하지 않는 독립 프로젝트입니다.

## 검증

```bash
uv sync --extra dev
uv run pytest
uv run ruff check .
```

검증에는 입력 해석, 출처 분류, 응답 형식, 오류·시간 초과, 키 비노출, 화면 계약, 카드뉴스 3장 형식·출처 검증 등이 포함됩니다. 모의 응답 테스트와 실제 LIVE 실행은 구분합니다. 제출 전 실제 API 키로 예시 클릭과 직접 검색을 실행하고 데스크톱·390px 모바일에서 확인해야 합니다. 카드뉴스는 생성·문구 수정·PNG 저장 후 파일 열기까지 확인합니다.

## 한계

- **매장 근거 확인은 검색 결과 대조입니다.** 매장명 핵심 단어는 출처의 제목 또는 URL에 있어야 하고, 지역은 제목·요약·URL에서 대조합니다. 상호가 요약에만 등장하는 자료는 제외합니다. 문서 전체를 읽는 검증이 아니므로 관련 자료를 놓치거나 동명이점·오래된 자료가 섞일 수 있습니다. 사업자·영업 상태·채널 소유를 공식 인증하는 기능은 아닙니다.
- **검색 범위는 공개 웹에 한정됩니다.** 비공개 SNS나 검색되지 않는 채널의 누락을 곧 매장 정보 부재로 단정하면 안 됩니다.
- **점수와 추천은 수집 자료에 따른 추정입니다.** 실제 매출·고객 행동이나 모든 AI 검색 노출을 측정하지 않습니다.
- **생성 원고는 초안입니다.** 출처와 가격·주소·영업시간 등 사실, 업종별 표현을 확인하고 발행해야 합니다.
- 스타일은 로컬 CSS, Pretendard 폰트는 CDN을 사용합니다. 폰트를 못 받으면 시스템 글꼴을 사용합니다.

촬영 대본은 `docs/demo-script.md`, 제출 기획서는 `docs/Geo_Channel_Auditor_기획서.pdf`입니다.
